La web necesita más drama. Akumu Films fue el inicio de mi exploración del suspenso y terror como narrativas, pero ahora quiero llevar esa sensibilidad cinematográfica al diseño web.

Cada click debería sentir como el inicio de una película. Las animaciones CSS (glitch, scanlines) no son solo decoración — son herramientas narrativas que crean una experiencia visual y táctil.

El escritorio BS-OS es mi statement: un sitio web no tiene que ser una página plana. Puede ser un espacio que habitas, exploras, y donde descubres cosas. Como una película, pero interactiva.
